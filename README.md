# timgulden.github.io

Public web pages for Tim Gulden's apps, served by GitHub Pages at
https://timgulden.github.io/.

- `/watchbeat/` — WatchBeat support page (App Store Support URL)
- `/watchbeat/privacy/` — WatchBeat privacy policy (App Store Privacy Policy URL)

Plain static HTML and one stylesheet; no build step (`.nojekyll` serves
files as-is). App source code lives in separate private repositories.

The WatchBeat privacy policy must stay accurate to what the app does
with audio, motion and debug reports. Any app change that touches
storage or transmission updates this page in the same release.
